# Wrytr Page

Static Vite project migrated from the exported Wrytr Sites page.

Target repository:
https://github.com/offbody/wrytr-page

## Local preview

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Contents

- `index.html` - exported published Wrytr landing page markup
- `assets/` - CSS and font files used by the exported page
- `favicon.svg` - site favicon
- `package.json` - lightweight Vite setup for local preview and static builds

This is the Wrytr marketing/page project. The Wrytr dashboard/app project belongs separately in `https://github.com/offbody/wrytr-app`.
